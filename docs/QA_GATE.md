# ATRIA QA Gate

A candidate cannot be promoted unless all are true:

- Boot: first load, returning profile, reload, background/resume.
- Lobby: player/HUD/chat/entities visible; no stale message; People works; return-to-lobby works.
- Vega and Solo: movement, NPC proximity, chat, anamnesis, exam, monitor, medication, studies.
- Studies: relevant + irrelevant orders, pending ETA, native abnormal precedence, universal fallback, persistence, slash autocomplete.
- Performance: no map-only state; no duplicate main loops; sustained movement without severe frame stalls.
- Coop/Competitive: 2 clients minimum; roster, start, movement, chat, reconnect, scoring.
- Voice: lobby + shared modes; clinical dictation does not clip first syllable.
- Mobile: keyboard, chat height, controls, background/resume.
